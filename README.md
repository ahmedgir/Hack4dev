# Hack4Dev Exoplanet Discovery Webapp

> **For judges:** start with the [three-minute review](JUDGES.md), then open the [frontend guide](webapp/frontend/README.md). The site builds as a static Next.js export for Vercel.

منصة عربية/إنجليزية تشرح كيف تتحول صور التلسكوب الخام بصيغة FITS إلى منحنى ضوئي قابل للفحص، وكيف نستدل على عبور كوكب معروف أمام نجمه دون الادعاء بأن الكوكب ظاهر في الصورة.

المشروع موجّه لتحدي **Discovery Tool**، ويجمع بين تحليل FITS، القياس الضوئي التفاضلي، فحص جودة البيانات، وتجربة تعليمية لغير المتخصصين.

## النتيجة الحالية

آخر تحديث للتحليل: **2026-09-17**.

تم تدقيق كل ملفات البيانات، وبناء Proof of Concept قابل للإعادة لتسع جلسات مكتملة المعالجة عبر سبعة أنظمة. النظام الثامن، TrES-1، لم ينتج حل إحداثيات موثوقًا لأن الإطارات لا تحتوي عددًا كافيًا من النجوم:

| النظام والجلسة | الإطارات المقبولة | قبل/داخل/بعد العبور | التشتت | الحكم |
|---|---:|---:|---:|---|
| WASP-10 — 2026-08-08 | 31/86 | 4/27/0 | 4.276% | غير كافٍ |
| WASP-2 — 2026-08-11 | 22/78 | 0/22/0 | 0.855% | لا يوجد خط أساس |
| WASP-2 — 2026-08-24 | 40/77 | 0/9/31 | 9.468% | ضوضاء مرتفعة |
| CoRoT-2 — 2026-08-09 | 73/87 | 11/45/17 | 1.690% | عبور أولي واعد |
| CoRoT-2 — 2026-08-16 | 85/86 | 11/44/30 | 1.650% | عبور أولي واعد ومتكرر |
| TrES-3 — 2026-08-10 | 34/70 | 0/22/12 | 3.665% | غير كافٍ |
| Qatar-1 — 2026-08-21 | 72/74 | 18/33/21 | 1.644% | شبيه بالعبور لكن معاملاته غير متسقة |
| TrES-5 — 2026-08-20 | 44/74 | 17/12/15 | 13.835% | تغطية كاملة لكن ضوضاء مرتفعة جدًا |
| HAT-P-10 — 2026-09-05 | 68/93 | 0/46/22 | 0.939% | لا توجد قياسات مقبولة قبل العبور |

في CoRoT-2 ظهرت استعادة متسقة في ليلتين: عمق `3.18%` ثم `2.88%` مقابل `2.75%` منشورًا، مع تغطية كاملة في المرتين. هذه **استعادة أولية متكررة لعبور معروف** وليست اكتشافًا مستقلًا أو تأكيدًا نهائيًا. Qatar-1 يوضح لماذا لا تكفي هيئة المنحنى وحدها: التغطية جيدة لكن العمق والمدة لا يتفقان مع المنشور.

اكتمل أيضًا التحقق المتقاطع لليلتي CoRoT-2 باستخدام **EXOTIC 4.3.1**. أعاد البرنامج قياس عمق `2.38 ± 0.45%` ثم `2.65 ± 0.35%`، مع تشتت بواقي `1.51%` و`1.43%`. النتيجتان متوافقتان مع العمق المنشور وتدعمان التصنيف الأولي، لكنهما تستخدمان البيانات الخام نفسها ولذلك لا تمثلان رصدًا مستقلًا. التفاصيل وطريقة الإعادة موثقة في [تقرير تحقق EXOTIC](docs/EXOTIC_VALIDATION_AR.md).

## مسار مراجعة الحكّام (3 دقائق)

1. افتح الصفحة الرئيسية ثم **CoRoT-2** لمشاهدة ليلتين وTimeline يربط كل نقطة بإطارها.
2. افتح **Qatar-1** لرؤية مثال يبدو كعبور لكن معاملاته لا تتفق مع المنشور.
3. افتح **TrES-5** و**HAT-P-10** لرؤية كيف تمنع الضوضاء أو نقص baseline الادعاء العلمي.
4. راجع المنهجية والمصادر في الموقع، ثم شغّل أوامر التحقق أدناه.

**الادعاء الأساسي:** الأداة لا تكتشف كوكبًا جديدًا؛ بل تجعل مسار الدليل من FITS إلى حكم علمي قابلًا للفحص، بما في ذلك الإطارات المرفوضة وحالات الفشل.

## ما الذي يميز الأداة؟

ليست مجرد عارض صور أو منحنى نهائي. ميزتها هي **سلسلة أدلة قابلة للتدقيق** تصل الصورة الخام بالاستنتاج: كل إطار له وقت وقياس وجودة وحالة قبول وسبب رفض، ويمكن للمستخدم الانتقال بين الصورة والنقطة المقابلة على المنحنى. كما تعرض الأداة الجلسات الفاشلة ولا تخفيها، وتفصل بين سلامة الملف، نجاح المعالجة، وصلاحية الحكم العلمي.

## رحلة البيانات في ثماني خطوات

1. عرض صورة FITS بتمديد بصري مناسب.
2. بناء Master Dark وطرح ضوضاء الكاميرا.
3. حل موضع الصورة في السماء وإنتاج WCS.
4. تحويل إحداثيات RA/Dec للنجم إلى X/Y داخل الصورة.
5. قياس ضوء النجم داخل Aperture وطرح خلفية السماء.
6. مقارنة الهدف بمجموعة نجوم Gaia.
7. تكرار القياس مع تتبع انجراف المجال عبر الزمن.
8. رسم منحنى الضوء ومقارنته بموعد وعمق ومدة العبور المنشورة.

## البدء السريع

### 1. استنساخ المستودع

```powershell
git clone git@github.com:ahmedgir/Hack4dev.git
cd Hack4dev
```

### 2. إنشاء البيئة

```powershell
conda env create -f environment.yml
conda activate exoplanet-poc
```

### 3. إضافة بيانات FITS

الصور الخام غير موجودة في Git لأن حجمها نحو `1.1 GB`. ضعها وفق البنية الموضحة في [docs/DATA_SETUP_AR.md](docs/DATA_SETUP_AR.md).

### 4. تشغيل النتائج المحفوظة أو إعادة التحليل

بعد إضافة البيانات، يعيد هذا الأمر تشغيل الجلسات التي تملك حلول WCS محفوظة دون انتظار الإنترنت:

```powershell
.\run_poc.ps1 --cached-only
```

ولتوزيع الجلسات المستقلة على عدة عمليات متوازية (كل جلسة تكتب داخل مجلد مخرجات منفصل):

```powershell
.\run_poc.ps1 --cached-only --jobs 3
```

القيمة الافتراضية لـ`--jobs` هي `1` للحفاظ على التشغيل التسلسلي السابق. لا تشغّل الجلسة نفسها مرتين بالتوازي لأنها تكتب الملفات نفسها.

لتشغيل جلسة واحدة:

```powershell
.\run_poc.ps1 --target CoRoT-2 --date 2026-08-09 --cached-only
```

عند معالجة حقل جديد بلا WCS محفوظ، يحاول الـpipeline أولًا مطابقة نجوم الصورة
مباشرة مع Gaia، ويتحقق من عدد النجوم والتشتت والمقياس والدوران ووجود نجم عند
الموضع المتوقع. يبقى ASTAP ثم Astrometry.net مساري fallback فقط إذا فشلت هذه
المطابقة المقيدة.

للتحقق من توفر ASTAP المحلي وقواعد النجوم على جهاز Windows:

```powershell
python scripts/check_astap.py
```

لإثبات فحص كل ملفات FITS وبناء تقرير اكتمال كل جلسة:

```powershell
python scripts/audit_dataset.py
python scripts/build_completeness_report.py
```

ولإنشاء صور الـTimeline—بما فيها الإطارات المرفوضة—لجلسة محللة:

```powershell
python scripts/build_timeline_previews.py --target CoRoT-2 --date 2026-08-09
```

### 5. فتح الدفاتر

```powershell
python -m jupyter lab
```

- `notebooks/00_see_the_data.ipynb`: رؤية FITS وDark لأول مرة.
- `notebooks/01_transit_pipeline_poc.ipynb`: مراجعة النتائج والجودة.
- `notebooks/02_manual_corot2.ipynb`: شرح يدوي مبسط من الصورة إلى منحنى الضوء.

## حدود علمية يجب عدم إخفائها

- الكوكب غير ظاهر في صور FITS؛ الدائرة تشير إلى النجم المضيف.
- لا توجد Flat أو Bias frames ظاهرة في مجموعة البيانات، ولدينا غالبًا Dark frames قليلة.
- نتيجتا CoRoT-2 أوليتان ومتوافقتان، واجتازتا تحققًا متقاطعًا بـEXOTIC على البيانات نفسها؛ هذا لا يحولهما إلى رصد مستقل أو تأكيد نهائي.
- الرسوم ثلاثية الأبعاد في مواقع NASA توضيحية وليست صورًا حقيقية لهذه الكواكب.
- يجب عرض الإطارات المرفوضة وأسباب رفضها، لا حذفها بصمت.
- ASTAP مثبت وجُرّب آليًا على 18 جلسة غير مخبأة، لكنه لم يحل أي صورة `650×500` منها. المطابقة المحلية المقيدة مع Gaia حلّت TrES-5 وHAT-P-10 وتحققت من أكثر من 140 نجمًا في كل حقل؛ يبقى Astrometry.net fallback ثم تُحفظ نتيجة WCS لإعادة التشغيل.
