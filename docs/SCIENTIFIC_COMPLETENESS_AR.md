# بوابة اكتمال المرحلة العلمية

هذه المرحلة لا تُعد مكتملة لمجرد أن صورة أو منحنى واحد يبدو مقنعًا. نستخدم ثلاث طبقات منفصلة من الإثبات:

1. **سلامة الملفات:** فتح كل ملف FITS وقراءة جميع بكسلاته وهيدره وتسجيل بصمته SHA-256 ومؤشرات التشبع والقيم غير الصالحة.
2. **اكتمال الـpipeline:** وجود WCS ثم قياس كل إطار في الجلسة، سواء قُبل أم رُفض، مع سبب رفض صريح.
3. **صلاحية الاستنتاج:** تغطية مناسبة قبل العبور وداخله وبعده، وتشتت منخفض، ثم تحقق مستقل بأداة مثل EXOTIC قبل استخدام لغة قوية.

## كيف نثبت أن كل الصور فُحصت؟

شغّل:

```powershell
python scripts/audit_dataset.py
python scripts/build_completeness_report.py
```

النتائج القابلة للتحقق موجودة في:

- `outputs/audit/fits_file_audit.csv`: صف لكل ملف FITS، مع نجاح القراءة والبصمة والإحصاءات.
- `outputs/audit/fits_audit_summary.json`: ملخص مستوى الملفات.
- `outputs/audit/session_completeness.csv`: صف لكل جلسة يوضح أين وصلت.
- `outputs/audit/session_completeness.json`: ملخص جاهز للواجهة أو CI.

عبارة **audited** لا تعني أن العبور قيس. وعبارة **pipeline complete** لا تعني أن النتيجة العلمية صحيحة. هذه الفواصل متعمدة لمنع المبالغة.

## عقد الـTimeline للموقع

كل جلسة مكتملة تنتج `web_timeline.json` وفيه صف لكل صورة، دون حذف المرفوضات. يحتوي الصف على:

- رقم الإطار واسم الملف والوقت؛
- نقطة منحنى الضوء والنموذج المتوقع؛
- `accepted`؛
- `rejection_reason`؛
- SNR وخلفية الصورة وعدد نجوم التسجيل؛
- انزياح X/Y؛
- مسار صورة WebP المتوقعة.

لبناء المعاينات المحلية لكل صورة:

```powershell
python scripts/build_timeline_previews.py --target CoRoT-2 --date 2026-08-09
```

المعاينات المولدة لا تدخل Git افتراضيًا لتجنب تضخيم المستودع. عند بناء الموقع نقرر أي جلسات تُنشر ونصدر صورها.

## حالة ASTAP

ASTAP مثبت وقابل للاستدعاء آليًا. لكنه لم يحل حقول `650×500` الحالية في المسح المحلي حتى الآن؛ عدد النجوم الصالحة لبناء الأنماط قليل بسبب صغر الصور وشدة undersampling. يسجل كل فشل في `astap_attempt.json`. لذلك لا يُعد ASTAP حلًا ناجحًا للبيانات الحالية، ولا تُخلط محاولة ASTAP مع توفر WCS من Astrometry.net.

## شرط الانتقال للموقع

يمكن بدء تصميم الموقع عندما تتوفر جلسة واحدة قوية لشرح النجاح وجلسة أو أكثر لشرح الفشل، ويكون كل إطار في هذه الجلسات ممثلًا في Timeline مع سبب القبول أو الرفض. أما الادعاء العلمي النهائي فيحتاج تحققًا مستقلًا؛ واجهة الموقع لا تعالج هذه الفجوة وحدها.
