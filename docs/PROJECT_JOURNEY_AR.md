# رحلة المشروع والقرارات

هذا الملف يلخص أهم ما خرج من جلسات العمل مع Codex كي يستطيع الفريق متابعة المشروع دون قراءة محادثة طويلة أو تكرار الأخطاء.

## البداية

كانت الفكرة الأولى منصة بحث وترتيب للكواكب. بعد فحص البيانات اتضح أنها ليست جدول كواكب ولا مجموعة ML مصنفة، بل 1,681 صورة علمية زمنية و60 Dark frame لثمانية نجوم مضيفة عبر 22 جلسة. لذلك تحول الاتجاه إلى Discovery Tool تشرح كيف تصبح الصور دليلًا قابلًا للفحص.

## أول سوء فهم مفيد

ظهرت صورة WASP-10 بيضاء تقريبًا وDark frame منقطًا. السبب لم يكن فساد البيانات، بل عرض FITS دون intensity stretch مناسب. تعلمنا أن البيانات العلمية لا تشرح نفسها، وأن الواجهة يجب أن تبدأ بالسياق لا بالرسم الخام.

## ما الذي نراه؟

WASP-10 وCoRoT-2 هما النجمان المضيفان. الكواكب لا تظهر كبقع داخل هذه الصور. الذي نقيسه هو انخفاض ضوء النجم عندما يعبر الكوكب أمامه. أي حركة للنجوم في الصور سببها انجراف التلسكوب/الكاميرا وليست حركة الكوكب المرئية.

## خطأ تحديد WASP-10

تجربة Gaia هندسية مبكرة استخدمت تسع مطابقات فقط وتركت residual بنحو 38 بكسل. الصورة الناتجة كانت مضللة ورُفضت. بعد اختيار reference frame أفضل وحل Astrometry.net حقيقي اكتُشف أيضًا خطأ اتجاه محور Y بين PNG وFITS، ثم ثبت WASP-10 عند موضع صحيح. الدرس: لا نرسم دائرة عامة قبل نجاح WCS أو تحقق مستقل.

## النتائج الأولى

جلسات WASP-10 وWASP-2 أثبتت عمل الـpipeline لكنها لم توفر تغطية وجودة كافيتين لإثبات عبور. أضفنا `fit_valid` ووسم `diagnostic_only` ومنعنا الإطارات المرفوضة من تحطيم مقياس الرسم.

## أول نتيجة واعدة

اخترنا CoRoT-2 لأن له أربع جلسات وعبورًا عميقًا نسبيًا. فحص الجودة رشّح 2026-08-09، ثم أنتجت:

- 73/87 إطارًا مقبولًا.
- 11/45/17 نقطة قبل/داخل/بعد العبور.
- عمقًا أوليًا 3.18% مقابل 2.75% منشورًا.
- مدة 2.51 ساعة مقابل 2.27 ساعة.
- فرق منتصف يقارب أربع دقائق.

هذه استعادة أولية لعبور معروف، وليست اكتشافًا مستقلًا.

## النموذج الذهني المتفق عليه

```text
FITS image
→ Master Dark
→ plate solving / WCS
→ catalogue RA/Dec to pixel X/Y
→ aperture photometry
→ comparison-star ensemble
→ repeat through time
→ light curve versus published ephemeris
```

## مصادر المعلومات

- ملفات FITS: البكسلات، وقت الرصد، التعريض، الموقع الجغرافي، اسم الهدف وتوجيه تقريبي.
- Dark frames: ضوضاء المستشعر التي تُطرح بكسلًا ببكسل.
- NASA Exoplanet Archive: RA/Dec الدقيقة، period، transit epoch، duration وdepth المنشورة.
- Astrometry.net حاليًا: تحويل نمط النجوم إلى WCS؛ الحلول مخزنة محليًا.
- Gaia: النجوم الفهرسية ونجوم المقارنة.
- Pipeline: القياسات والحكم والملفات المشتقة.

## القرارات المؤجلة عمدًا

- الواجهة النهائية والهوية البصرية.
- الاستضافة.
- أي ML؛ لا توجد مشكلة ML ضرورية مثبتة حتى الآن.
- الادعاء العلمي النهائي قبل EXOTIC وجلسة ثانية.

## ما يجب ألا نعيده

- لا نعيد plate solving للحلول المخزنة.
- لا نرفع 1.1 GB من FITS إلى Git.
- لا نعيد اختراع photometry أو transit fitting قبل مقارنة EXOTIC.
- لا نعرض 3D أو صورة فنية كأنها رصد حقيقي.
- لا نخفي الإطارات المرفوضة أو حدود البيانات.
